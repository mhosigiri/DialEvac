# Floodplain X-Ray map: handoff (index)

The user picked **Floodplain X-Ray** from `../map-style-options-v2/` and asked for:
1. day and night modes that switch by the real time,
2. more detail as you zoom in,
3. flood drawn only where flooding actually happens,
4. thunderstorm and hurricane illustrations,
5. live building, watched in the browser pane.

The result is a standalone app in this folder. Haven (`../haven-map-prototype/`) has **not** been touched.

## Run
```
cd outputs/floodplain-map && python3 tools/serve.py     # http://127.0.0.1:4178 (Cache-Control: no-store)
```

## Files
| File | Role |
|---|---|
| `index.html` | Layout: brand card; panel with Light (Auto/Day/Night, plus sun text), Hazards chips and Motion; legend; HUD; `#fx` and `#rain` overlays. Script order matters (see below). |
| `assets/vendor/maplibre-gl.*` | MapLibre GL JS **5.6.2**, copied from v2. 5.6+ is required for `color-relief`; 5.5+ for multidirectional hillshade. |
| `assets/base-style.js`, `assets/data.js`, `assets/footprints.js` | Copied byte-for-byte from `../map-style-options-v2/assets/`: the OpenFreeMap Positron style, the synthetic households, and OSM building footprints. |
| `assets/sun.js` | NOAA solar-position maths: `SUN.elevation`, `SUN.nextCrossing`. |
| `assets/style.js` | `PAL.night` / `PAL.day` palettes and `buildStyle(mode)`: terrain, relief, contours, 3D buildings and households. |
| `assets/app.js` | Controller: light mode, hazard registry and UI, motion, animation loop and boot. |
| `assets/hazard-flood.js`, `hazard-storm.js`, `hazard-hurricane.js` | Hazard plug-ins. They push to the `HAZARDS` array. |
| `assets/flood.js` | GENERATED by `tools/build_flood.py`: `FLOOD_BOUNDS` and per-household `FLOOD_HAND`. |
| `tiles/flood/{12,13,14}/…png` | GENERATED: HAND (height above nearest drainage) as Terrarium raster-dem, 84 tiles. |
| `tools/serve.py` | Dev server on port 4178, no caching. |
| `tools/build_flood.py` | Builds the flood layer (method in steps/03). |
| `images/` | Verification screenshots from the final run (steps/06). |

Script order: maplibre → base-style → data → footprints → maplibre-contour@0.1.0 (unpkg) → sun → flood → style → app → hazard-flood → hazard-storm → hazard-hurricane. Hazards register after `app.js` defines `HAZARDS`; `boot()` runs on DOMContentLoaded, after all of them.

## Steps (read in order)
1. `steps/01-setup-day-night/HANDOFF.md`: scaffold, palettes, sun-driven mode.
2. `steps/02-zoom-detail/HANDOFF.md`: zoom-dependent detail.
3. `steps/03-flood/HANDOFF.md`: HAND flood model and animation, with exact commands.
4. `steps/04-thunderstorm/HANDOFF.md`: simulated radar squall line plus lightning and rain.
5. `steps/05-hurricane/HANDOFF.md`: satellite-style hurricane, cone, track and wind rings.
6. `steps/06-validation/HANDOFF.md`: what was actually verified, the bugs fixed, and known limits.

## Status (Nov 7 2026)
All five asks are built and verified live in the browser pane (steps/06). All households and hazards are **illustrative**. The HUD says so, and nothing here is a forecast. Next decision for the user: integrate this into Haven, or keep iterating on the look.
