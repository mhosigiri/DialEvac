# Historical Houston demonstration

`crawled/houston_flooded_houses.json` is a saved extract described as Houston 311 flood reports. Its 4,370 records span August 23–October 25, 2017; they contain 4,007 distinct address strings, duplicates and intersections. The extract omits original request categories and source URLs. It is not a verified list of distinct flooded homes or current rescue requests. The other saved facility and tornado files also need source verification before operational use.

Run `python3 data/scripts/prepare_houston_history.py` from the repository root to regenerate `shared/houston-history.ts`. It selects the nearest 150 distinct addresses and coordinate pairs within 8 km of the Houston demo center, excluding intersections, missing/invalid coordinates and addresses without a street number. It retains original addresses, coordinates, case numbers, neighborhoods and report timestamps. Report coordinates are not independently verified building entrances.

From `services/`, `npm run demo:history` previews the import; `npm run demo:history -- --seed` adds it to the isolated demo database using the existing private operator token. It never targets the operational database. Repeating the import preserves prior records, answers, assignments and completed work. The 147 unassessed locations await a simulated field check; three fictional households have oxygen, wheelchair and stretcher transport scenarios. All contacts use reserved fictional 555-01xx numbers. No calls, texts or timers are started by the import.

The portal shows the historical case/date in the pickup card. **Get directions** opens the in-app OpenStreetMap-based street map with the committed OSMnx road route and a Gemini brief overlay. Assign a responder first; directions use that unit's stored coordinates as origin and the reported coordinates as destination. The driver app defaults to the isolated demo database and offers the same destination in its navigation tab. The road service uses OpenStreetMap/OSMnx; a historical location does not establish current road safety.

For the hackathon, the publisher may enable `DEMO_PUBLIC_DISPATCH=true` alongside `DEMO_MODE=isolated`. This permits all browser identities to use operator actions only while every stored household and vehicle is simulated. Service-only and internal actions retain their grants. Disable the temporary setting with `spacetime publish hackutd-richardson --server maincloud --env-only --unset-env DEMO_PUBLIC_DISPATCH --no-config --yes=remote,migrate,skip-login` from a shell without that variable exported. Existing identity grants then apply again. This setting does not enable browser dispatch on the operational database.
